# Step 7: The Fridge — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tapping the Note card opens the Fridge, which shows today's note, the notes before it and the family's makes. Old notes open large. A make with a link opens in a WebView that stays on its own site. `/api/today` stops sending every note ever drawn.

**Architecture:** The backend splits note rows out of the day cards. `/api/today` carries only the newest note, and `GET /api/notes` serves the last dozen. Makes stay in the sheet, and their Drive picture links are rewritten to a thumbnail URL. On the tablet: a `FridgeScreen` (a notes strip plus a makes grid), a large-note overlay, a `MakeScreen` (a WebView with a host guard), a new drawing, and the shared ink-only drawing decoder moved off the main thread.

**Tech Stack:** TypeScript, vitest. Kotlin 2.0, Jetpack Compose (BOM 2024.09.03), kotlinx-serialization, OkHttp 4.12, Coil (all already in the app), `android.webkit.WebView` (platform), JUnit 4. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-fridge-design.md`

## Review Focus

1. **The payload fix.** `/api/today` must carry exactly one note (the newest by id), whatever its priority, and every non-note card as before. A birthday posted months ago with a future `show_from` must survive 200 notes. (Task 1.)
2. **The WebView can't leave the make's site.** Only top-level navigations are guarded (`shouldOverrideUrlLoading`), so sub-resources from CDNs still load. Other schemes (`intent:`, `market:`, `javascript:`) are blocked, there are no new windows and no downloads. (Task 5, `SameHostTest`.)
3. **Decoding is off the main thread.** The strip can decode up to 12 PNGs pixel by pixel. `produceState` + `Dispatchers.Default`, keyed by note id. (Task 3.)
4. **The pencil still draws.** It sits inside a clickable card, and the inner `clickable` must win. "Never mind" and "Put it on the fridge" go back to where the drawing was started (Home or the Fridge). (Task 7.)
5. **Offline / no backend.** The Fridge shows today's note at once from `/api/today` and makes from the cached payload. A failed `/api/notes` adds one line of text and nothing else. (Task 6.)

// (imports: Bitmap, BitmapFactory, Base64, Image, Composable, getValue, produceState,
//  Modifier, ImageBitmap, asImageBitmap, toArgb, ContentScale, Ink, Dispatchers, withContext)

// A stylus drawing as ink on the paper behind it, cropped to its strokes. Decoded
// on a background thread: the Fridge strip decodes up to a dozen at once, pixel by pixel.
@Composable
fun DrawingImage(png: String?, key: Any, modifier: Modifier = Modifier) {
    val bitmap by produceState<ImageBitmap?>(null, key) {
        value = png?.let { withContext(Dispatchers.Default) { decodeDrawing(it) } }
    }
    bitmap?.let { Image(it, contentDescription = "a drawing", contentScale = ContentScale.Fit, modifier = modifier) }
}

private fun decodeDrawing(b64: String): ImageBitmap? = runCatching {
    val bytes = Base64.decode(b64, Base64.DEFAULT)
    BitmapFactory.decodeByteArray(bytes, 0, bytes.size)?.let(::inkOnly)
}.getOrNull()
```

package home.brimley.ui

// (imports: SuppressLint, WebResourceError, WebResourceRequest, WebView, WebViewClient,
//  background, layout.*, MaterialTheme, Text, Composable, getValue, mutableStateOf, remember,
//  setValue, Alignment, Modifier, TextOverflow, dp, AndroidView, Make, Ink, Paper, java.net.URI)

// A make with a link (a Scratch game, a story on a web page), opened in kiosk.
// No address bar, no new windows, no downloads, and it can't leave the make's site.
@SuppressLint("SetJavaScriptEnabled")
@Composable
fun MakeScreen(make: Make, onBack: () -> Unit) {
    val link = make.link.orEmpty()
    var failed by remember(link) { mutableStateOf(false) }
    Column(Modifier.fillMaxSize().background(Paper)) {
        Row(
            Modifier.fillMaxWidth().height(110.dp).background(Ink).padding(horizontal = 30.dp),
            verticalAlignment = Alignment.CenterVertically,
            horizontalArrangement = Arrangement.spacedBy(24.dp),
        ) {
            InkButton("← Back to the fridge", onClick = onBack, filled = false, onPaper = false)
            Text(make.title, style = MaterialTheme.typography.headlineLarge, color = Paper, maxLines = 1, overflow = TextOverflow.Ellipsis, modifier = Modifier.weight(1f))
        }
        Box(Modifier.fillMaxSize()) {
            AndroidView(
                factory = { ctx ->
                    WebView(ctx).apply {
                        settings.javaScriptEnabled = true
                        settings.domStorageEnabled = true
                        settings.allowFileAccess = false
                        settings.setSupportMultipleWindows(false)
                        setDownloadListener { _, _, _, _, _ -> }
                        webViewClient = object : WebViewClient() {
                            override fun shouldOverrideUrlLoading(view: WebView, request: WebResourceRequest): Boolean =
                                !sameHost(link, request.url.toString())
                            override fun onReceivedError(view: WebView, request: WebResourceRequest, error: WebResourceError) {
                                if (request.isForMainFrame) failed = true
                            }
                        }
                        loadUrl(link)
                    }
                },
                onRelease = { it.stopLoading(); it.destroy() },
                modifier = Modifier.fillMaxSize(),
            )
            if (failed) {
                Column(Modifier.fillMaxSize().background(Paper), horizontalAlignment = Alignment.CenterHorizontally, verticalArrangement = Arrangement.Center) {
                    FridgeIllustration(Modifier.size(160.dp))
                    Spacer(Modifier.height(18.dp))
                    Text("This one didn't open. Ask a grown-up to check the link.", style = MaterialTheme.typography.titleMedium, color = Ink)
                }
            }
        }
    }
}

// Top-level navigations may stay on the make's own host (http or https). Everything
// else, other sites, subdomains, intent: and javascript: links, is swallowed.
fun sameHost(base: String, url: String): Boolean {
    val a = runCatching { URI(base) }.getOrNull() ?: return false
    val b = runCatching { URI(url) }.getOrNull() ?: return false
    if (b.scheme?.lowercase() !in setOf("http", "https")) return false
    val host = a.host ?: return false
    return host.equals(b.host, ignoreCase = true)
}
```

// "Today", "Yesterday", a weekday within the week, else "Sep 30". Null when the
// date is missing (today's note as /api/today sends it carries none).
fun noteDay(createdAt: String, today: LocalDate, zone: ZoneId): String? {
    val day = runCatching { OffsetDateTime.parse(createdAt).atZoneSameInstant(zone).toLocalDate() }.getOrNull() ?: return null
    val ago = java.time.temporal.ChronoUnit.DAYS.between(day, today)
    return when {
        ago == 0L -> "Today"
        ago == 1L -> "Yesterday"
        ago in 2..6 -> day.dayOfWeek.getDisplayName(java.time.format.TextStyle.SHORT, java.util.Locale.US)
        else -> day.format(java.time.format.DateTimeFormatter.ofPattern("MMM d", java.util.Locale.US))
    }
