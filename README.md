# brimley-home

Family dashboard for the kitchen, built for a Daylight DC-1.

Nothing is built yet. Start here:

- `docs/design-directions.html` — five visual directions, each mocked at the DC-1's
  4:3 shape in grayscale, with notes and a recommendation. Open it in a browser.
- `docs/woodcut-round-2.html` — the chosen direction (Woodcut) refined: home screen,
  the all-jobs-done moment, and the album and show pickers.
- `docs/round-3.html` — current: Fredoka type, four-card hierarchy with one Playing
  card, the "Play something" picker, and the phone page for adding shows.
- `docs/PROPOSAL.md` — what the dashboard does, how it is put together (native Android
  app + a small Vercel/Supabase backend, reusing Crate for music), and the open questions.
